# RIV013 コンテンツ構成

## 有効な100枠

| 系列 | 件数 | 出現方式 | 主な役割 |
|---|---:|---|---|
| 通常漂着物 | 86 | 重み付きランダム | 人間の生活、都市、魔法機械、異常 |
| 主人の手紙 | 8 | 固定順・一度限り | 都市の現況、主人の消息、猫への心配 |
| 記憶エピソード | 6 | 固定順・一度限り | 猫と主人が暮らした時間 |
| 合計 | 100 | 混成 | 世界と主筋を両立 |

## 固定順

```text
手紙1 → 春の病院
手紙2 → 夏のシャワー
手紙3 → 秋の爪切り
手紙4 → 冬の毛布
手紙5 → おなかの罠
手紙6 → 四季の窓辺
手紙7 → 手紙8
```

終盤の手紙7〜8には回想を挟まず、都市・意識接続・主人の現在へ集中する。

## 役割分担

### 主人の手紙

- 現在の異常がどこまで進んだか
- 友人へ何を頼んでいるか
- 猫を迎えに行けない理由
- 猫を置いていったわけではないこと
- 主人が帰還を諦めていないこと

### 記憶エピソード

- 病院を嫌がった春
- シャワーで細くなった夏
- 爪切りに苦労した秋
- 寒くなるとくっついた冬
- 腹を撫でると噛んで蹴ったこと
- 四季ごとの家の匂いと居場所

### 通常漂着物

- 人間が戻らない生活用品
- 魔法機械都市の残骸
- 水が物・音・記憶へ及ぼす異常
- 猫の家に似た断片的な痕跡

## 文体規則

- 人類滅亡を直接断定しない。
- 主人の手紙は友人宛ての私信として書く。
- 猫は文字を「主人の声の形」として理解する。
- 回想は「思い出した」と説明せず、感覚の列として出す。
- 通常物は一ページ、主人の手紙だけ複数ページを許す。
