# RIV013 物語記述ルール

## 三系列を混ぜない

### 通常漂着物

- 一ページで読み切る。
- 見えるもの、匂い、手触り、動作だけを書く。
- 人類滅亡や都市崩壊の答えを直接書かない。
- 世界の空白をプレイヤーに推測させる。

### 主人の手紙

- 友人へ宛てた私信として書く。
- 都市の現況、友人への依頼、猫の安全、帰還の意志を進める。
- 病院、シャワー、爪切り、腹への反撃、冬、四季の詳細回想を入れない。
- 3〜5の手動ページ境界を持つ。
- 主人が生存しているとも死亡しているとも断定しない。

### 記憶エピソード

- 原則一ページ。
- 猫の映像、音、匂い、体温、身体感覚として書く。
- 「思い出した」「過去の記憶だ」と説明しない。
- 主筋を進めず、猫が主人を探す理由だけを深める。

## 中核表現

- 猫は文字を、主人の声と視覚の対応として理解する。
- 「人がいなくなった」と書かず、「人が戻ってこなかった物」を置く。
- 明るく生命の多い自然と、人間不在の痕跡を対照させる。
- 強い手掛かりを一度に複数出さない。
- 第7通から第8通の間には回想を挟まない。
